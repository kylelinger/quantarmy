# 量化军团 (QuantArmy)

> 让普通人拥有华尔街级别的量化交易团队

## 项目简介

量化军团是一个Web平台，用户可以像组建公司一样，通过"雇佣"AI Agent和Skills来创建自己的量化交易团队。支持股票和加密货币模拟交易。

**所有交易均为模拟盘，不涉及真实资金。**

## 核心理念

- 普通人也能拥有专业量化团队
- 全球开源策略/工具一键适配
- AI驱动的智能组装与运行

## 技术栈

- 前端: Next.js + TypeScript + Tailwind CSS
- 后端: Python FastAPI
- AI适配层: LLM-powered skill integration
- 数据: Binance API / Yahoo Finance / 各交易所公开数据
